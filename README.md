# 爪爪动物园 2.0 · 重新开园

原生 JavaScript + Canvas 2D 微信小游戏，无广告、无充值、无服务器依赖。保留八位动物的原有美术，通过合成经营一座重新开放的动物园。

## 四个页面

- **合成**：7×7 图案棋盘、普通心愿与挑战单。八级动物、饮品和果实链，三个生产器可切换、升级。普通心愿保底保留容易需求。
- **园区**：六个园区、24 次修复。金币、星星和棋盘材料用于建设；修复逐步开启生产器、仓库扩容、赠礼和收益加成。入住的居民会出现在所属园区。
- **故事**：六章、24 个目标。原创新剧情围绕一封没有署名的信展开；章节选择保存在日记中，可回看已完成的故事。
- **庆典**：三种循环主题、每轮三个里程碑，奖励金币、星星、道具和园区配色；每日三个短目标。解救萌友有 20 个独立的 4×4 空间谜题。

解救萌友每关初始 9～11 个图案，含内部障碍与狭窄通道，目标提升到五至七级，步数仅比验证参考解多 1～3 步。开始新挑战、重试、重玩和下一关各消耗 30 体力；当前未失败的一局可退出后继续，重载续局不重复扣费。体力不足不扣费、不重置当前局；关卡选择页可免费补满体力。

## 合成、居民与经营

动物链：**哈巴狗 → 水豚噜噜 → 月薪猫 → 肥嘟嘟 → 懵兔 → 耳朵龙 → 黄油小熊 → 爪爪鸟**。

饮品链：**VC柠檬茶 → 茉莉奶绿 → 拿铁 → 泰奶红茶 → 黑巧美式 → 黑糖珍珠 → 芭乐茉莉 → QQ美莓奶茶**。
果实链：**咖啡豆 → 巴旦木坚果 → 蓝莓 → 苹果 → 芭乐 → 柠檬 → 沙糖桔 → 柚子**。

相同类型、等级二合一；支持拖动、点选后点目标、移动空位和交换位置。棋盘格仅显示图案。新局随机铺入 22 个一级、10 个二级动物。动物小窝初始产出概率仍为 65%/20%/10%/5%，每次消耗 1 体力，随机进入空格。

左侧生产器卡片只有生成动作，整个卡片均可点击。切换与升级统一从棋盘上方右侧的“生产器管理”进入，避免连续生成时碰到管理入口。设置中点击“兑换码”，输入中文 **爪爪鸟** 可立即解锁全部生产器并保存；不改变园区、剧情、金币、体力或生产器等级，重复兑换不重复发放。重新开始新局会清除该解锁状态。

解救萌友采用直接四向滑动：从任意图案向上、下、左、右划一下即可移动一格，同级相遇自动合成；不用预先选中，也不用拖到目标格。轻点、轻微抖动和方向不明确的斜划不消耗步数。剩余三步时数字醒目提醒；步数用尽出现持续遮罩提示与重试／返回关卡入口，遮罩下的棋盘无法操作。图鉴统一从主界面右上角进入。

前两张订单仍叫“心愿 1”“心愿 2”，普通单按容易/中等/较难 60%/30%/10% 抽取，保底至少一张容易单；右侧挑战单保留高等级目标。交单获得金币、星星和经验。金币用于建设、换单和升级，星星用于园区修复，经验提升园长等级并给予奖励。

修复迎风小院一次开启饮品吧，两次开启果香小屋。果香小屋初始产出咖啡豆（80%）和巴旦木坚果（20%），每次消耗 1 体力；升级后可产出蓝莓。每个后续园区在前一个修到 2/4 后开放。动物入住需要消耗棋盘上对应动物，并修好它所在园区的一间小屋。八位居民各有最爱的饮品、十级亲密度，在 3/6/10 级分别解锁一封专属来信，共 24 封。

仓库初始六格，可扩为九格，修复月光水岸后可扩至十二格。选择棋盘物品后可收纳、用剪刀拆为两个低一级物品，或用星光糖升一级。没有空间、材料或道具时不会扣除资源。满盘也可合成、交单、收纳，或确认移出物品。

体力初始 100，每 90 秒恢复 1 点。设置里随时可以免费休息补满。居民每分钟积攒金币，离线最多计入八小时；奖励不会因重载重复领取。故事结束后仍可经营、培养居民、举办庆典、完成每日目标和重玩试炼。

## 运行与存档

微信开发者工具打开本目录，项目类型保持“小游戏”，点击 **编译 → 预览**。入口是 game.js，现有 AppID 已保留。本次没有执行上传或发布。

浏览器预览：运行 npm run preview 后打开 http://127.0.0.1:4173 。
安全区预览：http://127.0.0.1:4173/?safeTop=44&safeBottom=34&capsule=1 。

2.0 使用独立本地存档键 **paw-zoo-2.0-save**（格式版本 3），首次运行开始新的动物园。不读取或迁移 1.x 存档。之后自动保存棋盘、居民、建设、故事、试炼、静音和配色。进度保存在当前设备；需要换设备时没有云存档。

七种本地短音效保留，合成 0.16 秒、连合 0.21 秒，可静音并保存偏好，切后台停止播放。

## 项目结构与扩展

| 文件 | 职责 |
| --- | --- |
| js/merge/config.js | 三条合成链、生产器、初始棋盘、订单参数 |
| js/merge/model.js | 基础合成、订单、连合和基础存档 |
| js/merge/zoo.js | 建设、居民、道具、剧情、庆典、时间与 2.0 存档 |
| js/merge/content.js | 六园区、六章节、八居民与来信、庆典、每日目标数据 |
| js/merge/puzzles.js | 可解谜题生成与独立试炼规则 |
| js/merge/game2.js | 触控、生命周期、保存和页面操作 |
| js/merge/view2.js / art.js | 自适应布局、场景与透明素材绘制 |
| js/merge/sound.js | 音效与静音 |
| images/characters/ / images/drinks/ / images/fruits/ / images/zoo/ | 八张原角色图、八张透明饮品图、八张透明果实图、原创园区背景 |
| tests/ / preview/ / tools/ | 本地验证与预览工具，不上传 |

新增物品链在 config.js 中配置稳定 ID、等级和 image 图片路径，并添加生产器。新增园区、章节、居民和来信主要修改 content.js。修复、交单、赠礼和故事捐赠都使用统一物品需求格式。
