# 爪爪动物园

原生 JavaScript + Canvas 2D 微信二合一小游戏，无广告、无服务器依赖。

## 玩法

- **7×7 棋盘**，新局随机铺入 22 个哈巴狗、10 个水豚噜噜。格子只显示图案，名称在心愿和图鉴里显示。
- 八级合成链：**哈巴狗 → 水豚噜噜 → 月薪猫 → 肥嘟嘟 → 懵兔 → 耳朵龙 → 黄油小熊 → 爪爪鸟**。一个爪爪鸟相当于 128 个哈巴狗，可边生产边合成。
- 相同类型、相同等级二合一；可拖到空格，也可交换不同物品，或先点选再点目标格。
- 心愿区左侧的小窝每次随机生成一个物品：哈巴狗（一级）65%、水豚噜噜（二级）20%、月薪猫（三级）10%、肥嘟嘟（四级）5%。随机落到空格，各级均消耗 1 体力。**初始体力 100**，设置里可免费补满。
- 普通心愿混合容易、中等和较难需求，基础概率为 60%/30%/10%；生成或刷新时若其他普通心愿没有容易单，则保底补一张容易单。新生成的容易单只需一种 1～3 级物品、1～2 个，不随章节加量，界面统一显示“心愿 1”或“心愿 2”。新局第一单也降低了数量。
- 组合心愿必须满足全部需求才能提交；最右侧挑战单从五级懵兔逐步提升到八级爪爪鸟。
- 每五单进入下一章并领取奖励，前四章逐步增加较难订单和挑战单的数量。
- 连续合成从第三次开始每次额外获得 2～6 金币。整理位置不打断；生成、交单、移出、换单会结束连合，无倒计时。
- 心愿右上角可消耗金币换单（30 金币起）。换单和重置都需确认。
- 图鉴、静音和自动存档；棋盘满时可选中物品后“移出棋盘”。

## 运行

微信开发者工具打开项目目录 `D:/Develop/merge2`，类型保持“小游戏”，点击 **编译 → 预览**。入口是 `game.js`，AppID 保持原值。

本地浏览器预览：

```powershell
npm run preview
```

打开 http://127.0.0.1:4173 。模拟安全区可用 http://127.0.0.1:4173/?safeTop=44&safeBottom=34&capsule=1 。

进度保存在当前设备本地，使用 `paw-zoo-save-v2`，只读取当前八级格式。旧测试版本不迁移、不备份。首次使用新键会开新局，之后正常自动保存。

订单难度调整继续使用现有八级存档。已有高难订单不会在启动时被替换；重新编译后刷新前两张中的任意一张，或完成普通订单，便会按新规则生成。

## 音效

七个本地短音效对应生成、移动、合成、连合、交单、晋级和操作提示；设置可静音，尊重手机静音开关，切后台停止播放。

普通合成约 **0.16 秒**，连合约 **0.21 秒**，采用低音量、平滑起音、少高频泛音的柔和音色。

`node tools/generate-sounds.js` 可重新生成音效，无外部依赖。

## 扩展和结构

| 文件 | 用途 |
| --- | --- |
| `js/merge/config.js` | 角色链、生产器、初始铺图、订单、体力及难度参数 |
| `js/merge/model.js` | 合成、组合订单、连合、章节与存档 |
| `js/merge/game.js` | 触摸、生命周期、保存、操作反馈 |
| `js/merge/view.js` | 布局、棋盘、心愿、图鉴和设置 |
| `js/merge/sound.js` | 音效及静音 |
| `images/characters/` | 八张透明角色图 |
| `sounds/` | 七个本地 WAV |

添加角色链时，在 `chains` 填写稳定 ID 和各级角色数据，再将生产器 `outputs` 指向该链。初始铺图由 `starterFill` 的类型、等级、数量决定；订单使用 `requirements` 数组，最多两个不同物品。图鉴超过五个角色可左右翻页。

未使用的打飞机模板已清理。预览、测试、音效生成脚本和文档不随小游戏上传。
